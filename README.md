# Co-Evolution

A living, generative artwork about humans and AI growing together. Living growth rises from below, digital growth descends from above, and where they meet each bends a little toward the other.

- **index.html**: the full piece, with reaction-diffusion patterns.
- **light.html**: the same garden without the patterns, for slower computers.

Listening and spoken answers need a Chrome-based browser (Chrome 148 or newer) that can run the on-device Gemini Nano model. Tapping, typing, sound and the patterns work everywhere.

Do not put an API key in these files: this repository is public.
